# Nothing Glyph SDK

Lync's Glyph feature (Nothing phones only) needs Nothing's Glyph SDK. Its licence doesn't allow
redistribution, so it isn't in this repo. To build with Glyph support, download
`glyph-matrix-sdk-2.0.aar` from
https://github.com/Nothing-Developer-Programme/Glyph-Developer-Kit/tree/main/sdk and put it here.

Without the file the app builds normally and the Glyph settings are hidden.
