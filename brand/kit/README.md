# Lync logo

An Android droid living in your Mac's notch: the bar is the top of the Mac's screen, the head hangs from it.

Every file in `out/` is generated by `build_kit.py`. Change the geometry or colours there and run
`python3 build_kit.py`; never edit the generated files by hand.

## Construction

Everything derives from two numbers: the bar height **H** (170) and the head radius **R** (570).

| Part | Rule |
|---|---|
| Bar | Height H, corner radius H/5. Full width in the wide mark; head + 0.30R each side in the compact mark |
| Head | Circle of radius R centred on the bar's centre line; only the part below the bar shows |
| Eyes | Radius R/12, centres 0.45R either side of the middle and 0.5R below the head's centre |
| Antennae | Width H/5 with round ends; each starts on the head's outline directly under an eye and leans out at exactly 30°; length 0.36R |
| Small cut | Same construction; eyes 0.115R, antennae 2.2 × wider and 0.40R long. Use it below 64 px wide |

## Colour

| Name | Hex | Use |
|---|---|---|
| Forest | `#0F2E24` | Icon field, the mark on light backgrounds |
| Mint | `#7FE3B0` | The mark on Forest or other dark backgrounds |

One-colour black and white versions are included for print, stamps and system templates.

## Which file to use

| Need | File |
|---|---|
| Mark on light backgrounds | `lync-mark-forest.svg` |
| Mark on dark backgrounds | `lync-mark.svg` (mint) or `lync-mark-white.svg` |
| Mark with the name | `lync-lockup-forest.svg`, `lync-lockup.svg` (mint), `-black`, `-white` |
| Small spaces (below 64 px wide) | `lync-compact-small-*.svg` |
| Mac app icon | `AppIcon.icns` (from `icon-mac.svg`, Apple's 1024 template) |
| Android launcher | `ic_launcher_foreground.xml`, `ic_launcher_monochrome.xml`, background `#0F2E24` |
| Android notification | `ic_stat_lync.xml` |
| Mac menu bar | `MenuBarIcon.png`, `MenuBarIcon@2x.png` (template images, 18 pt tall) |

## Rules

- **Clear space:** keep at least one bar height (H) of empty space around the mark and the lockup.
- **Minimum size:** the wide mark at 64 px wide; below that, the compact small cut (down to 16 px tall).
- **In the app icon,** the bar always runs off both edges of the tile: the tile is the Mac's screen.
- **Lockup:** "Lync" in Figtree SemiBold, outlined. Capitals are 55% of the bar-to-chin height and centred on
  it; the gap to the word is 0.40R. Don't retype the word in another font.
- **Don't** rotate, stretch, outline, add shadows or gradients, recolour outside the palette, or put Mint on
  light backgrounds (too little contrast).

## Notes

- The Android robot itself isn't used: this droid is drawn from scratch and only shares the general idea
  (a domed head, dot eyes, antennae). Apple's logo isn't used anywhere.
- A professional trademark search is still needed before a wide public launch, for both the name and the mark.
- Figtree is licensed under the SIL Open Font License, which allows its use in a logo.
